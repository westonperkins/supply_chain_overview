**Reason vocabulary (frozen).**
- `no_node` — no node — the graph models no entity for this mention
- `alias_unknown` — alias unknown — a node exists but this name isn't in its aliases
- `ambiguous` — ambiguous — the mention could resolve to more than one node
- `out_of_domain` — out of domain — a real entity deliberately outside the AI graph

**Disposition vocabulary (frozen).**
- `alias` — alias — add this name to an existing node's aliases
- `new_node` — new node — model this entity as a new graph node
- `noise` — noise — not a real supply-chain entity; ignore
- `defer` — defer — a real candidate, but not promoted this pass
- `undisposed` — undisposed — no disposition authored yet
